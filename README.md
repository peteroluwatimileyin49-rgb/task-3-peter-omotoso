# SQL Data Analysis

This project was completed as part of the DecodeLabs Internship Program.

## Project Overview

The goal of this project was to use SQL queries to extract insights from a dataset by writing SELECT queries, filtering records with WHERE, sorting with ORDER BY, grouping with GROUP BY, and calculating summary metrics such as COUNT, SUM, and AVG.

## What I Did

- Wrote SQL SELECT queries to retrieve relevant data
- Used WHERE clauses to filter rows based on conditions
- Used ORDER BY to sort the results
- Used GROUP BY to organize data into meaningful categories
- Performed basic aggregations using COUNT, SUM, and AVG
- Summarized the key insights from the data
- Documented the findings and business meaning of the results

## Tools Used

- SQL
- MySQL / PostgreSQL / SQLite
- Database client such as DBeaver, MySQL Workbench, or SQLite Studio
- Microsoft Excel or Google Sheets for data review and verification

## Project Deliverables

- `project-3-queries.sql` — SQL queries used for the analysis
- `project-3-dataset.csv` or `project-3-dataset.xlsx` — dataset used for the analysis
- `project-3-analysis-report.pdf` — summary of the findings and insights
- `proof-of-work/` — screenshots showing query execution and results

## How to Review

1. Open the SQL file and review each query.
2. Check how the WHERE clauses filter the data.
3. Review the ORDER BY and GROUP BY logic.
4. Confirm the COUNT, SUM, and AVG calculations.
5. Read the PDF report for the narrative summary of findings.
6. Review the proof-of-work screenshots for evidence of the results.

## Result

The dataset was analyzed successfully using SQL, and the key insights were extracted through filtering, grouping, and aggregation.
